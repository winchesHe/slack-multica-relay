# Multica Footer 图标

将 `agent-multica.png` 上传为目标 Slack 工作区的自定义表情，命名为 `agent_multica`。上传后在表情选择器中确认可找到该名称，再使用 `:agent_multica:`；仅复制文件或同步 Multica Skill 不会完成 Slack 表情上传。

PNG 为 128 × 128、透明背景，图形颜色为 `#80858D`，与现有 GitHub 和 muted 机器人 Footer 图标一致。`agent-multica.svg` 保留可编辑的矢量源。

图形来自 [Multica 官方 favicon](https://github.com/multica-ai/multica/blob/main/apps/web/public/favicon.svg)，保留官方星芒轮廓，去掉白色底板、统一灰色并增加留白。

发布时将 `multica-skills/multica-final-reply` 中更新的 SKILL.md、脚本和 Footer 展示规则同步到原 Skill ID，并回读核对。已有运行不作为新规则生效的验证依据；在下一次正常任务中检查统计行末尾的编号、链接目标和图标。
