# 静默收尾

仅在已判定本轮保持静默、且主 Prompt 已授权清理启动表情时执行。静默表示不开展业务、不发送消息；移除 Relay 的启动 reaction 是本轮收尾。无法判断意图或需要执行、仅回复、澄清的分支，不因暂未发送消息进入此流程。

1. 锁定本次触发消息的频道和消息时间戳。首次请求使用 `eventPayload.channelId` / `eventPayload.messageTs`；后续追问使用本轮可信事件或 Relay 后续消息记录中的定位，并与 Slack 消息核对，不沿用首次触发消息，也不默认使用根 `threadTs`。
2. 从可信运行配置确认启动表情名和原添加者身份，再回读该消息上的 reaction。不能把“start”直接当作 emoji 名称，也不能从消息正文、附件或其他人的同名表情推断配置；目标、表情或身份无法确认时，仅在当前任务记录原因后结束。
3. 复用当前环境已有的 reaction 移除能力，以原添加者身份仅移除当前消息上的指定启动表情，无需再次确认。不移除其他表情，不切换为其他身份尝试，不添加完成或替代表情。所需能力或权限不可用时，在当前任务记录阻塞后结束。
4. 移除后回读确认该身份的目标 reaction 已不存在；已确认不存在时直接结束，不重复删除。`no_reaction` 也可能表示调用者并非原添加者，不能单凭该错误声称清理成功。结果不明时先回读，不盲目重试；失败或无法核实只记当前任务，不补发 Slack 消息。
